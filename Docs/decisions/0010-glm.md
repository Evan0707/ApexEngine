# 0010 — Ajout de GLM (mathématiques)

**Date :** 19 novembre 2026
**Statut :** acceptée (plan de la phase 3 validé par le développeur le 19 novembre 2026)

## Contexte

La phase 3 introduit la caméra, les transformations des objets et la projection. Le cahier des charges retient GLM pour les mathématiques, utilisable par tous les modules (section 3.2), et `Core` peut en dépendre (section 4.2). La décision 0006 a reporté son ajout à la phase 3.

## Décision

- Ajouter `glm` à `vcpkg.json` : version 1.0.3 dans la baseline, à confirmer à l'installation.
- `Core/Math.h` est le seul point d'inclusion de GLM : les autres fichiers incluent `Core/Math.h`. Les options de GLM y sont fixées une fois pour toutes, et seules les extensions stables (`glm/ext`, `glm/gtc`) sont utilisées, jamais `glm/gtx`.
- `Core/WorldPosition.h` définit `WorldPosition`, alias de `glm::vec3` (garde-fou G-07).
- Les conventions de la section 3.3 sont appliquées par des fonctions du moteur, pas par des options globales de GLM : la projection (profondeur 0 à 1, inversion de Y) est construite dans une seule fonction de `Graphics`.

## Alternatives écartées

- **Option `GLM_FORCE_DEPTH_ZERO_TO_ONE` :** elle change en silence le comportement de toutes les fonctions de projection. Une fonction explicite (`perspectiveRH_ZO`) dit la même chose à l'endroit où elle sert.
- **Bibliothèque mathématique maison :** du code à écrire et à tester, sans gain pour le prototype.

## Conséquences

- Modules touchés : `Core`, puis `Resources`, `Graphics` et `Game`. GLM est la seule bibliothèque tierce autorisée dans les en-têtes publics de tous les modules (section 3.2).
- Garde-fous : G-07 (`WorldPosition`), G-10 (conventions de repère).
- Licence : MIT, ajoutée à `ThirdPartyLicenses.md`.
- Retour en arrière : coûteux dès que les types GLM sont dans les interfaces, comme pour toute bibliothèque mathématique.
